## 🎨 Design System

### Colors
```css
--primary-blue: #0B9FFF
--dark-blue: #0A7FD9
--black: #000000
--dark-gray: #2d3748
--gray: #4a5568
--light-gray: #718096
--border: #e2e8f0
```

### Typography Scale
```
Hero: 68px (800 weight)
Section Titles: 48-52px (800 weight)
Card Titles: 22-24px (700 weight)
Body: 15-16px (500 weight)
Small: 13-14px (500 weight)
```

### Spacing
```
Section Padding: 100px vertical
Card Padding: 28-40px
Gap Between Cards: 28-32px
Border Radius: 16-20px (cards), 50px (buttons)
```
